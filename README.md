# SiteSolvo — debesies darbo repo

Šis repo tęsia SiteSolvo (svetainių tobulinimo paslaugos) outreach darbą Claude Code debesies sesijose, greta lokalios Mac sesijos `~/Documents/SiteVersa`.

Visas kontekstas, taisyklės ir darbo eiga — `CLAUDE.md`. Skaityti jį pirmiausia, ypač viršuje esančią pastabą apie tai, kas dar neperkelta iš lokalios sesijos (pilnas `outreach_tracking.csv` žurnalas, atminties failai, siuntimo scriptai, Gmail kredencialai).

`outreach_tracking.csv` šiame repo šiuo metu turi tik antraštę — realus 73+ eilučių žurnalas gyvena lokaliai ir turi būti importuotas čia prieš pradedant naują laiškų partiją šioje sesijoje.
